# YananXFreya 的个人主页

主页地址：https://yananxfreya.github.io/

这是一个无需安装依赖的静态主页初稿。`index.html` 包含页面内容与样式，可直接用浏览器打开。个人介绍、简历和项目目前均使用明确的占位说明。

## GitHub Pages 设置

- 仓库：`YananXFreya/yananxfreya.github.io`
- 可见性：Public
- Settings → Pages → Source：Deploy from a branch
- Branch：main，目录：/(root)

后续可直接修改 `index.html`，或替换为选定的个人主页模板。提交到 `main` 分支后，GitHub Pages 会自动重新发布；可在仓库的 Actions 页面查看部署进度。
