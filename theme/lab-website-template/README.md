The SCSS modules in this directory are unmodified upstream source files.
assets/template.css combines them after removing Jekyll front matter and compiling with Sass 1.83.4.
The citation-card structure is adapted from the template's citation component;
personal layouts and bilingual content are rendered by tools/build_site.py.
This is a static adaptation, without Jekyll or a Ruby runtime requirement.
The original laboratory examples, team pages, and demo assets are not included.

The template license covers the website code. It does not relicense personal
documents or research figures; those retain their respective authors' rights.
